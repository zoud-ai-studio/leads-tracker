# Architecture run memlog

- decision: The PRD binds a static Next.js browser application with localStorage only; no backend or database.
- decision: One versioned storage envelope and a repository boundary own all browser persistence.
- decision: Local-calendar date-only strings govern follow-up and won-month calculations.
- decision: Pure domain modules own validation, formatting, queries, aggregates, and CSV serialization.
- decision: Browser-created lead IDs use static query-parameter routes instead of Next.js dynamic route segments.
- decision: Activities carry both an ISO ordering timestamp and local calendar date; the lead memo remains distinct from activity entries.
- decision: Malformed or unknown-version storage is preserved and reported, and tabs refresh their in-memory view on storage events.
- assumption: `wonAt` is captured on the transition into Won, matching the PRD default for “Won this month”.
- question: Product has not selected empty states, onboarding text, CSV column order, or a global default sort direction.
- version: Next.js static export, Tailwind CSS with Next.js, React Testing Library, and Playwright were checked against official documentation on 2026-11-09.
- event: architecture spine finalized
